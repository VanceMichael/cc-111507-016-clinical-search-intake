# 匿名协作服务目录来源格式

采用 FHIR R4 JSON searchset，不支持临床写入。/fhir?page=1 返回初页，后续严格使用 Bundle.link[next]，token 失效返回 OperationOutcome。entry.search.mode 为 match/include/outcome，缺 mode 标为 unknown，total 只作来源声明。资源身份为 resourceType/id/meta.versionId，fullUrl 是该 bundle 的引用别名；_history 指定版本必须准确解析，未指定版本不自动替换成任意历史资源。只访问网关本源内链接。输出匹配记录与附带资源分别计数，OperationOutcome 放 issues，重复页和循环 next 不视作完整。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://hl7.org/fhir/R4/search.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。

## 本机场景

`fixtures/scenarios.json` 中的场景用于覆盖采集边界，全部为合成资料：

| 场景 | 采集结果 |
| --- | --- |
| standard / partial-outcome | 两页，第二页含 outcome 告警，跨页重复附带资源合并，state=partial |
| clean | 两页无告警，引用均可解析，state=complete |
| expired-next | 第二页返回 410 OperationOutcome，保留 issue，state=partial |
| looping-next | next 指回第一页，重复页不重复计入，state=partial |
| version-mismatch | 引用 `_history/2` 但结果集只有版本 1，不替换，state=partial |
| ambiguous-versions | 未指定版本的引用对应两个版本，不擅自选择，state=partial |
| unknown-mode | 条目缺少 search.mode，不计入匹配，state=partial |
| outside-next | next 指向来源以外，不跟随，state=partial |
| truncated-page | 第二页正文中断，保留已读片段，state=partial |
| source-unavailable | 初页返回 503，无可用页面，state=rejected |
