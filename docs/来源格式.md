# 匿名协作服务目录来源格式

采用 FHIR R4 JSON searchset，不支持临床写入。/fhir?page=1 返回初页，后续严格使用 Bundle.link[next]，token 失效返回 OperationOutcome。entry.search.mode 为 match/include/outcome，缺 mode 标为 unknown，total 只作来源声明。资源身份为 resourceType/id/meta.versionId，fullUrl 是该 bundle 的引用别名；_history 指定版本必须准确解析，未指定版本不自动替换成任意历史资源。只访问网关本源内链接。输出匹配记录与附带资源分别计数，OperationOutcome 放 issues，重复页和循环 next 不视作完整。

`fixtures/scenarios.json` 给出本机来源入口、允许读取的资源及分页文件；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

结构化场景覆盖：`standard`（两页，含 outcome 与跨页重复 include）、`expired-next`（第二页 token 失效）、`partial-outcome`、`looping-next`、`cyclic-next`、`unsafe-next`、`duplicate-page`、`edge-references`（版本化/无版本/fullUrl 别名/未知 mode/扩展）、`clean`（单页可完整）与 `not-a-bundle`。

格式参考：https://hl7.org/fhir/R4/search.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
